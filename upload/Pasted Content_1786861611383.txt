IMPORTANT: STOP AND REBUILD THE EXAMINATION SCHEDULING LOGIC.

I have reviewed the current implementation again. The UI is not the biggest problem anymore. The underlying examination logic is currently wrong.

The current implementation is treating the combined subjects of all selected classes as one global list of papers.

That is incorrect.

For example, if 11 classes/groups are selected and the system says:

18 papers · 18 subjects

that does NOT mean the school needs 18 consecutive examination days.

You must redesign the scheduling model around:

CLASS → SUBJECTS → EXAM SLOTS

not:

SELECTED CLASSES → UNIQUE SUBJECTS → ONE PAPER EACH

This is a critical correction.

============================================================
1. THE FUNDAMENTAL EXAMINATION MODEL
============================================================

An examination is conducted for MULTIPLE CLASSES TOGETHER.

The selected classes participate in the same examination window.

The school should NOT conduct:

Class 6 exam separately
then Class 7 separately
then Class 8 separately
then Class 9 separately
etc.

That defeats the purpose of selecting multiple classes in the same examination.

Instead:

ONE EXAMINATION
→ ONE COMMON EXAMINATION WINDOW
→ COMMON EXAM DAYS
→ COMMON TIME SLOTS
→ CLASS-SPECIFIC PAPERS WITHIN THOSE SLOTS

Each class follows its own subject list.

The timetable must synchronize those class-specific papers into common slots.

8. NUMBER OF EXAM DAYS
============================================================

The scheduler must calculate the required number of examination days based on the MAXIMUM subject count among the selected classes.

Formula:

requiredDaysForClass =
ceil(numberOfExamSubjectsForClass / maxPapersPerDay)

Then:

requiredExamDays =
MAX(requiredDaysForEachSelectedClass)

Example:

Class 6 = 5 subjects
→ ceil(5 / 2) = 3 days

Class 7 = 6 subjects
→ ceil(6 / 2) = 3 days

Class 8 = 6 subjects
→ 3 days

Class 9 = 6 subjects
→ 3 days

Class 10 = 6 subjects
→ 3 days

Class 11 PCM = 5 subjects
→ 3 days

Class 11 PCB = 5 subjects
→ 3 days

Therefore:

COMMON EXAMINATION WINDOW = 3 working days.

If another selected class has:

10 subjects

then:

ceil(10 / 2) = 5 days.

Therefore the common examination window becomes:

5 working days.

This is the correct calculation.
